# React Pokedex

> Pokedex Interactiva con React y Material UI

## Resumen

Una aplicación Pokedex completa desarrollada en React que utiliza hooks modernos como useContext para gestión de estado, React Router para navegación, y Material UI para un diseño profesional. La aplicación integra la Pokemon API para proporcionar información detallada de todos los Pokemon con una experiencia de usuario moderna e interactiva.

## Valor del proyecto

Demuestra competencia en desarrollo React moderno, gestión de estado avanzada, integración de APIs externas, y creación de aplicaciones interactivas que pueden aplicarse en e-commerce, catálogos digitales, y aplicaciones de entretenimiento.

Este repositorio resume una pieza de producto pensada para explicar el problema, la solucion aplicada y el criterio tecnico detras de la implementacion.

## Funcionalidades o puntos fuertes

- Catálogo completo de Pokemon con búsqueda avanzada
- Gestión de estado global con useContext
- Navegación fluida con React Router
- Interface moderna con Material UI
- Sistema de filtrado por tipo, generación y habilidades
- Vistas detalladas de Pokemon individuales
- Diseño responsive optimizado para todos los dispositivos
